One word for the boss, for make.fun's "One Word for the Boss" bounty ($2, winner takes all). The entry is a single word — no phrase, no caption, no explanation — written by `main.py` to `/output/entry.txt`.

## The word

**Meetingizer** — the boss who turns every two-line email into a calendar invite, every invite into a recurring series, and every series into a pre-read. Funny because it is instantly recognisable, true because everyone has met one, fresh because it is not the first word anyone reaches for.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` (Python 3.13, stdlib only) writes the word `Meetingizer` (11 characters, no trailing newline) to `/output/entry.txt`.
